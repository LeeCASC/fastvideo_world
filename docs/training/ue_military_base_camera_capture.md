# Unreal Engine 军事基地场景相机轨迹与视频采集要求

## 采集规模与机位

- 静态场景：5 个机位，每机位采集 8 个方向 × 3 档速度，共 120 条视频。
- 动态场景：20 个机位，每机位采集 8 个方向 × 3 档速度，另采集 1 条相机静止的参考视频，共 500 条视频。
- 总计 620 条视频；每条连续 300 帧，统一使用 24 FPS、相同分辨率和固定镜头参数。

| 场景 | 机位安排 |
| --- | --- |
| 静态场景（5 个） | 基地入口、主道路、营房院落、机库或停机坪、车辆停放区各 1 个。 |
| 坦克编队（5 个） | 编队前外侧、后外侧、左翼、右翼、道路侧方高点；均在车辆行驶范围之外。 |
| 飞机编队（5 个） | 编队前斜侧、后斜侧、左侧、右侧、下方斜侧；均在航线之外，画面保留地面或其他静态参照物。 |
| 士兵（5 个） | 行进路线前侧、后侧、左侧、右侧、路旁高点；均在人员行进范围之外。 |
| 航空母舰（5 个） | 停泊状态下的甲板前部、后部、甲板外沿、舰桥侧方、码头或岸侧。航行场景只使用不附着于舰体的外部机位。 |

地面和甲板机位的相机距所在平面 1.6–2.0 m，优先 1.8 m；空中机位按编队高度设置并记录实际高度。起始相机保持水平、无滚转，画面包含近、中、远景静态参照物。所有速度档位的轨迹均须有足够空间，不得碰撞、穿模或使主要内容大面积出画。

## 相机轨迹与速度

以首帧主要静态物体的典型距离 `D` 定义**中速**轨迹。慢速、中速、快速在相同的 300 帧内分别执行中速运动总量的 **0.5、1、1.5 倍**；不得提前到达终点后静止。三档仅改变相机运动，场景时间线保持一致。

| 按键 | 中速轨迹终点 |
| --- | --- |
| W / S | 沿起始朝向水平前进 / 后退，各 `min(0.35D, 3.5 m)`。 |
| A / D | 沿起始相机方向水平左移 / 右移，各 `min(0.25D, 2.5 m)`。 |
| I / K | 原地向上 / 向下俯仰，各 8°。 |
| J / L | 原地向左 / 向右偏航，各 12°。 |

每条视频只执行一种相机运动。平移时保持高度和朝向不变，旋转时保持位置不变；对向动作幅度和时长相同。开头、结尾短暂平滑加减速，中段保持单方向稳定运动。整段固定焦距、视场角、对焦、曝光及相机内参。

## 动态场景与交付验收

同一机位的全部视频使用完全相同的第 0 帧、镜头参数和场景起始状态。动态场景的 25 条视频复用同一段物体运动时间线：任意对应帧的人物、车辆、飞机及舰船具有相同的世界坐标位置、姿态和动画状态。物体路径、速度、朝向、动画触发及生成时间不得响应相机位置或按键；相机不得跟踪物体。运动物体不得长时间遮蔽大部分静态背景。

固定或烘焙动态模拟，并统一起始时间、随机种子和渲染预热设置；重复渲染时逐帧状态须一致。交付逐帧视频、相机逐帧位置与旋转、内参及时间戳；动态场景另交付运动物体的逐帧世界坐标和动画状态。注明 Unreal Engine 坐标系、厘米单位、帧率、机位、动作和速度档位。逐机位核验首帧一致、八方向与三档速度正确，以及动态物体在对应帧的世界状态一致。
